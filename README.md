# Task Manager Demo

This is a deployed demo version of my Task Manager App built with React.

## Live Demo
[View the app](https://victor-osn.github.io/task-manager-demo/)

## Features
- Add a task
- Mark a task as complete or undo it
- Delete a task
- Save tasks in browser localStorage
- Keep tasks after page refresh

## Tech Stack
- React
- Vite
- CSS
- localStorage

## Note
This repository contains the GitHub Pages demo version of the project.

I also built a fuller version of this project using:
- React frontend
- Express backend

The demo version uses localStorage so it can be hosted publicly on GitHub Pages.
